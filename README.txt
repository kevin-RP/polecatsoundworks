POLECAT SOUNDWORKS WEBSITE

This version uses the approved Polecat studio concept for the opening visual,
but removes the concept's own top navigation so the website's existing navigation
bar remains the only navigation at the top.

1. Open index.html in a browser to preview.
2. The opening concept image is in assets/polecat-first-page-concept.png.
3. To publish free with GitHub Pages:
   - Create a GitHub account.
   - Create a new repository called polecat-soundworks.
   - Upload the contents of this folder.
   - In Settings > Pages, choose Deploy from a branch and select main.
4. The contact form currently opens the visitor's email app to send to:
   polecatsoundworks@gmail.com
